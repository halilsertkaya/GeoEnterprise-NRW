# 🏢 GeoEnterprise-NRW (OpenLayers Enterprise GIS)

An enterprise-grade Web-GIS application tailored for infrastructure monitoring and spatial data management in North Rhine-Westphalia (Cologne region), built with **OpenLayers**, **OGC Standards**, and **Bootstrap 5**.

🔗 **Live Demo:** <a href="https://halilsertkaya.github.io/GeoEnterprise-NRW/" target="_blank">View Live on GitHub Pages</a>

---

## 🚀 Key Enterprise Features
* **OpenLayers Core Architecture:** Built using robust enterprise-grade mapping library standards favored in German municipal and engineering GIS.
* **OGC-Ready Structure:** Configured to integrate seamlessly with standard WMS/WFS map servers (GeoServer / MapServer).
* **Vector Layer Management & Styling:** Custom canvas styling, coordinate projections (`EPSG:3857` to `EPSG:4326`), and dynamic layer toggles.
* **Feature Inspector:** Interactive spatial event handling for inspecting critical infrastructure assets and risk parameters.

## 🛠️ How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any browser. No backend required!
